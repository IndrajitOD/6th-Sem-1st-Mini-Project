# Blynk Dashboard

The recovered source code defines:

- **V0:** soil moisture percentage
- **V1:** manual pump control

A suitable dashboard could contain a moisture gauge/value widget connected to V0 and a switch connected to V1.

│ SMART IRRIGATION       │
│                        │
│ Soil Moisture: 42 %    │
│                        │
│ Pump Control: [ OFF ]  │
